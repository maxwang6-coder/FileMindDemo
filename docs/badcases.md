# 失败案例记录

只记录实际观察并可复现的问题。当前尚未建立检索评测，也没有在本次文档整理中复现历史故障，因此不编造失败数量、修复结论或模型效果。

## 记录模板

- 编号、日期与阶段：
- 代码 commit、依赖/配置版本（不含密钥）：
- 最小输入或自写样例：
- 复现命令/操作：
- 预期行为及其规格依据：
- 实际输出：
- 归因：配置 / 数据 / 解析 / 检索 / 模型 / 工具 / 页面 / 执行恢复。
- 修复与取舍：
- 防止复发的测试：
- 实际复测结果及未验证限制：

真实资料正文、用户路径和令牌不得写入公开记录。无法安全脱敏时只保留本机复现资料，在这里写匿名摘要。

## 后续应验证的场景

以下是测试计划，不是已发生的失败：前端未构建、未授权 API、错误 Host/Origin、重复启动、越界链接、无权限子目录、损坏 PDF、旧版本引用、模型超时与伪造引用。按阶段验证后，再将真实失败转为独立记录。
